
# 🛒 Banco de Dados E-commerce — SQL Server

Projeto de banco de dados relacional para um sistema de e-commerce, desenvolvido utilizando **SQL Server**, como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo aplicar conceitos de criação, estruturação e manipulação de bancos de dados, simulando operações de um comércio eletrônico por meio de comandos SQL, relacionamentos entre tabelas e consultas estruturadas.

## 📚 Sobre o projeto

O banco de dados foi desenvolvido para representar um ambiente de e-commerce, permitindo a prática de operações relacionadas ao armazenamento, à consulta e à manipulação de informações.

Durante o desenvolvimento, foram explorados recursos de SQL Server para estruturar os dados, estabelecer relacionamentos e realizar consultas utilizando diferentes técnicas da linguagem SQL.

## 💻 Conceitos e recursos utilizados

- **DDL (Data Definition Language):** criação e alteração de estruturas do banco de dados.
- **DML (Data Manipulation Language):** inserção, atualização e exclusão de registros.
- **Relacionamentos:** associação entre tabelas em um banco de dados relacional.
- **Constraints:** aplicação de restrições para garantir a integridade dos dados.
- **Views:** criação de consultas armazenadas para facilitar o acesso às informações.
- **CTEs (Common Table Expressions):** organização de consultas utilizando expressões de tabela comuns.
- **Consultas SQL:** recuperação e manipulação de informações armazenadas.

## Tecnologias utilizadas

- **SQL Server:** sistema gerenciador de banco de dados relacional.
- **T-SQL:** linguagem utilizada para criação, manipulação e consulta dos dados.
- **Git e GitHub:** versionamento e armazenamento do projeto.

## 📈 Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de bancos de dados relacionais.
- Criação e gerenciamento de tabelas utilizando SQL.
- Definição de relacionamentos e restrições de integridade.
- Manipulação de registros com comandos DML.
- Criação e utilização de Views.
- Construção de consultas utilizando CTEs.
- Organização de scripts SQL para resolução de problemas.

## Como executar o projeto

Para executar os scripts do banco de dados:

1. Tenha uma instância do **SQL Server** disponível.
2. Utilize uma ferramenta de gerenciamento compatível, como o SQL Server Management Studio (SSMS).
3. Clone ou baixe este repositório.
4. Abra os arquivos SQL disponíveis na pasta `bancoEcommerce`.
5. Execute os scripts na ordem adequada, respeitando as dependências entre tabelas e relacionamentos.
